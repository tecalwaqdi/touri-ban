## Preferred Arabic consistency
- Driver → **السائق** (not مندوب/كابتن unless a real business distinction exists)
- Agent → **الوكيل**
- Settlement → **التسوية** (with ة)
- Reconciliation → **المصالحة** (with ة)

## Do not translate
UID, Firebase ID, Order ID, Settlement ID, Payment ID, email, phone, URL, SHA, UUID, API, HTTP, CSV, PDF — keep LTR; translate surrounding labels only.
