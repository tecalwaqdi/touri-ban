## الملخص التنفيذي

النسخة الإنتاجية التي يجري إصلاحها هي تطبيق العميل `ara_oatan_app`. يوجد بجانبها تطبيق المندوب `mndob-main` ولوحة الإدارة `Admi`، وتوجد Firebase Functions وقواعد Firestore داخل كل مشروع. مشروع Firebase الفعلي لتطبيق العميل هو `tutorial-multi-language-70gx4j`، واسم حزمة Android هو `com.mycompany.araoatanapp` ومعرف iOS الحالي هو `com.mycompany.araoatanapp2`. لن يتم تغيير أي منهما ضمن هذا الإصلاح.

المشكلات الظاهرة في الصور ليست تجميلية فقط. جذورها موزعة بين نظامي ترجمة يعملان معاً، نصوص مولدة قديمة ناقصة، بيانات مواقع غير متجانسة، حساب مسار بديل غير محمي من الإحداثيات غير الصالحة، وحساب مالي مكرر داخل شاشة الحجز.

## مخاطر التنفيذ

- تغيير مخطط Firestore أو معرفات الحزم غير مطلوب وسيُتجنب.
- البيانات القديمة قد تحتوي أسماء عربية فقط؛ سيبقى العرض متوافقاً مع الحقول القديمة مع تفضيل حقول `namesI18n` و`descriptionsI18n`.
- لا يمكن اعتبار الدفع منشوراً قبل نجاح نشر Cloud Functions واختبار 3DS من نسخة التطبيق.
- لا يمكن ادعاء مراجعة بشرية أصلية لجميع اللغات؛ أدوات الفحص ستثبت الاكتمال التقني، بينما الصياغة النهائية للروسية والقيرغيزية وغيرها تحتاج متحدثاً أصلياً قبل النشر التجاري.
